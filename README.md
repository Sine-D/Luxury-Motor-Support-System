# 🚗 Luxury Motor Support System

## 📌 Overview

The **Luxury Motor Support System** is a web-based platform designed to enhance customer experience in the motor solutions industry. It allows users to browse vehicles, make purchases, and access customer support services seamlessly.

The system integrates multiple roles such as customers, admins, and support agents into one centralized platform.

---

## 🎯 Features

### 👤 User Roles

* **Guest**

  * View vehicles and services
  * Browse promotions
  * Send inquiries

* **Registered User**

  * Purchase and reserve vehicles
  * Access full vehicle details
  * Chat with support agents
  * Submit reviews and ratings

* **Support Assistants**

  * Handle customer queries
  * Manage complaints
  * Provide real-time assistance

* **Admin**

  * Manage users and services
  * Control system settings
  * Monitor performance

* **Marketing Manager**

  * Create marketing campaigns
  * Manage promotions
  * Analyze customer data
